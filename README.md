# Dolfan聊天室剪貼簿💬

上傳聊天室截圖，自動挑出「你」和「偶像」的訊息、去掉重複的，從原圖裁切後接成限動圖（1080×1920）或一張長圖。

## 隱私

- 截圖只在你自己的瀏覽器裡處理，不會上傳到任何伺服器。
- 這個網頁沒有後台、沒有帳號、不蒐集任何資料。
- 頁面上的範例截圖都是虛構的內容。

## 限制

- 聊天室背景如果換成照片，訊息會辨識不出來，請先換回預設（純色）背景再截圖。

- 請用手機原本的截圖，不要先裁切或縮放，拼起來最準。

## 怎麼用

1. 用手機打開網頁，選擇聊天室截圖（可多選）。
2. 檢查訊息列表：打勾的會放進圖裡，順序不對用 ↑ ↓ 調整。
3. 選擇「限動 9:16」或「一張長圖」，長按輸出的圖片存到相簿。

可以加上自己的帳號浮水印（下方置中、正中間或滿版斜排）。

⚠️ 兜粉官方規定：偶像的訊息不能連續截圖超過 10 句，偶像發的照片也請不要外流。

認錯訊息時，打開「辨識設定」調整偶像泡泡顏色或聊天區範圍。
